# Հայերեն տառադարձիչ

Լատինատառ գրված հայերենը ավտոմատ դարձնում է հայատառ։ Աշխատում է բրաուզերում և Node-ում, առանց կախվածությունների։

    hayeren  ->  հայերեն
    kody     ->  կոդը
    Barev dzez.  ->  Բարեվ ձեզ։

## Գործարկում
Բացել `index.html`-ը բրաուզերում։

## Օգտագործում կոդում
```js
const { convert } = require('./js/translit');
convert('hayeren'); // "հայերեն"
```

## Թեստեր
    npm test

## Կանոններ
- Երկտառ՝ `dz`ձ `ts`ց `ch`չ `sh`շ `zh`ժ `kh`խ `gh`ղ `dj`ջ `ph`փ `th`թ `rr`ռ `vo`ո `ee`է `oo`օ
- `o` → ո, `x` → խ, `c` → ց, `q` → ք, `u` → ու
- `y` + ձայնավոր → յ, այլապես (բառավերջ) → ը
- `ev` առանձին բառը → և, բառասկզբի `ye` → ե
